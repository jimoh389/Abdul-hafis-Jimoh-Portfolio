# Abdul-Hafis Jimoh — Portfolio

Personal portfolio website for Abdul-Hafis Jimoh, Product Manager based in Lagos, Nigeria.

Single-page static site (`index.html`) with no build step or dependencies.

## Run locally
Open `index.html` in any browser.

## Deploy with GitHub Pages
1. Push `index.html` to the root of the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The site goes live at `https://<username>.github.io/<repo-name>` (or `https://<username>.github.io` if the repo is named `<username>.github.io`).
